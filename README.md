# ⚽ Almanaque do Futebol Nostálgico

## 📖 Sobre o projeto

O **Almanaque do Futebol Nostálgico** é um site dedicado à história e à memória do futebol.

O projeto busca resgatar momentos marcantes do futebol, apresentando informações sobre **times históricos, grandes craques e uniformes clássicos**, valorizando a história que ajudou a construir a paixão pelo esporte.

## 🎯 Objetivo

Criar um espaço para conhecer e relembrar:

* 🏆 Times históricos
* ⭐ Grandes jogadores do passado
* 👕 Uniformes clássicos
* 📖 História do futebol
* ⚽ Momentos marcantes de diferentes épocas

## 💻 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
